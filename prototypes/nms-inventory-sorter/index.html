What we are deciding

Which layout makes “where items come from” and “where items go” obvious? Are optional settings easy to find without dominating the dialog?

Proposed behavior, not just appearance

Each category has one clear destination. Optional overflow handles extra space. Preview comes before applying. Capacity expansion is explicit and off by default. These are proposals for discussion—not changes to the app.

Not modeled: real game capacity limits, inventory/item compatibility, stack merging, save writing or installed-technology rules. No settings are persisted. Refresh or reset to start again.
