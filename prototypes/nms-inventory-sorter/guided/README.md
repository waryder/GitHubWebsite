# Variant: Guided steps

## Design stance
One decision at a time. Less to learn up front; more moving between steps.

## Key choices
- Layout: three-step dialog
- Typography: system font and familiar desktop controls.
- Color: neutral panels with blue primary actions.
- Interaction: source checkboxes, category destinations, optional overflow/expansion, dry-run preview and browser-only apply/reset.

## Trade-offs
- Strong at: first-use comprehension.
- Weak at: seeing all settings at once.

## Boundary
Invented fixtures only. Not a save codec, no backend, no real save access, no game compatibility claim.
