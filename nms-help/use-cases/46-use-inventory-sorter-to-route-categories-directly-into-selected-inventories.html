Use Inventory Sorter to route categories directly into selected inventories.

Use case 46 · Working with inventories

Help Index → Working with inventories → Use case 46

Route resource records directly with Inventory Sorter. Use this legacy dialog only when you accept immediate app-data changes and automatic target-grid expansion.

Before you start · Steps · Expected result · Saving · Check the result · Important details

Before you start

  1. Load and confirm the intended save/context. Create a full backup before direct sorting.
  2. Check remembered Sorter choices rather than assuming defaults.
  3. Before sync, formatting or structured refresh, copy EACH pending Raw JSON pane to its own external file: one sync can overwrite all others. Reapply non-inventory edits one pane at a time, syncing and comparing exact values before the next. Parse errors can leave an old tree with green status; [] is ignored, and Pretty Print can erase invalid text.
  4. Do not sync/Pretty Print Inventory Raw JSON: dictionary assignment is defective. Use Organizer for supported moves or Replace Items from Backup for supported replacement.
  5. If an earlier inventory record is missing, legacy Sorter captions can shift and misidentify storage types. Prefer Organizer’s stable-path roster; verify the actual inventory Name/Slots and destination contents, not the legacy caption alone.

Steps

  1. Preserve EACH pending pane externally before refresh: one sync can overwrite the others. Reapply non-inventory edits one pane at a time, syncing and verifying exact values. Stop after parse errors even if green; [] is ignored and Pretty Print may erase invalid text. Use structured tools, never defective Inventory Raw JSON sync/Pretty Print. (control reference)
  2. Open Inventory Processing → Node View → Inventory Sorter. Under Source Inventories, check Exosuit only and uncheck every other source. (control reference)
  3. Under Target Inventories, check Storage Container 1 (followed by the loaded inventory name) only and uncheck all other targets. Verify the actual Name/Slots, not just the caption; cancel and use Organizer if missing records make identity uncertain. In that target’s Categories selector, check Substance (Organic Resources) only; uncheck Product, Technology, Consumable, Trade and Special. (control reference)
  4. Uncheck Use All Unselected Storage Containers For Overflow to prevent additional containers from accepting records of any category. (control reference)
  5. Recheck the source, target and category choices, then click Execute Sort. There is no Review Moves or separate Apply step. Cancel instead if you do not want execution. (control reference)

Expected result

  1. Sorter reorders the target’s slot positions, resets its ValidSlotIndices to 120 cells and moves matching Substance records until the target’s capacity is reached. Matching records may remain in Exosuit.
  2. Source, target and category choices are stored for later Sorter use.

What changes, and when to save

Execute Sort edits app-model inventory data immediately, not the live save file. Inspect the changed views before File → Save writes the loaded target. Cancel before execution avoids the sort; it is not undo afterward. Stored Sorter choices and any exported backup are separate from live-save persistence. Compare every intended edit with its preserved copy before any live write; refreshed panes alone cannot prove preservation.

Check the result

  1. Inspect the actual source and destination Name/Slots, resources left behind and changed target positions. Read any warning even if Inventory has been sorted! follows; early validation can still announce success.

Important details and recovery

  1. The legacy caller can say Inventory has been sorted! after an internal missing-choice validation return; that notice alone proves nothing moved.
  2. Enabled overflow adds unchecked containers from Container 10 backward until the first checked container, and added targets accept all categories.
  3. Use Organizer with expansion unchecked if the target’s original capacity must be preserved.
