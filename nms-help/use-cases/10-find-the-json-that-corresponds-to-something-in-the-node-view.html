Use case 10 · Working with Node View and Raw JSON

Help Index → Working with Node View and Raw JSON → Use case 10

Use Highlight In Text Box to move from a node to its corresponding line in that tab’s Raw JSON. This is navigation, not an edit or export. It is safer than searching by a repeated value when you need the occurrence belonging to one particular node.

Before you start · Steps · Expected result · Saving · Check the result · Important details

Before you start

  1. Load the intended save and open the tab containing the record.
  2. Check the Raw JSON synchronization light. If pending text matters, resolve it deliberately before expecting node-to-text correspondence.
  3. Before any sync, Pretty Print or structured refresh, copy EACH pending Raw JSON pane’s complete text to a separate external file. Successful tab sync refreshes ALL Raw JSON panes and can erase pending text elsewhere.

Steps

  1. If several panes contain wanted pending work, preserve ALL before any refresh. If applying it, reapply and verify one non-inventory tab at a time; never simply sync each changed tab. Keep inventory text externally and reproduce supported changes with structured tools instead.
  2. In Node View, expand the record until the field or object you want is visible. You can use Toggle Expansion 2 Levels from a node’s right-click menu. (control reference)
  3. Right-click the actual node, not an empty area of the pane. Choose Highlight In Text Box. (control reference)
  4. Inspect the selected line in Raw JSON. Scroll nearby to see the containing object and its keys before identifying the value you intend to inspect. (control reference)
  5. If Highlight unavailable appears, read the reason. The app does not repair or synchronize text as part of this navigation command. (control reference)
  6. For intended non-inventory edits, preserve every pending pane first, then sync and verify just this tab before retrying navigation. Do not sync inventory text to repair highlighting; retain it externally and use Search Text for manual inspection. (control reference)

Expected result

  1. Successful navigation selects the whole corresponding text line and scrolls it into view.
  2. An unavailable mapping leaves text, tree and save data unchanged instead of jumping to a guessed duplicate.

What changes, and when to save

Highlighting changes cursor, selection and scroll position only. Any separate synchronization changes app memory; neither action saves live files. A refreshed pane is not proof that pending text survived; compare the intended values with your external copies before authorizing a live write.

Check the result

  1. Check that the selected line belongs to the intended record and not merely another field with the same value.
  2. For compact JSON, several fields may share one line; selection is a line, not a promise of an isolated value.

Important details and recovery

  1. Do not type while a line is selected unless you intend to replace that text.
  2. The linked Bases controls illustrate the shared workflow; use the matching tab’s Node View and Raw JSON panes.
  3. Inventory Raw JSON synchronization is currently defective: it adds index-keyed data inside inventory dictionaries instead of replacing the intended records. Do not sync or Pretty Print inventory text as an editing workflow; keep it externally, use supported structured inventory tools, and inspect actual Name, Slots and unexpected fields before saving.
