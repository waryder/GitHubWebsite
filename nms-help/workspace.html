Node View & Raw JSON

Two views of app data—not two independent save files.

The two panes

Node View lets you inspect structured records and use contextual actions. Raw JSON lets you view and edit the text for the active tab. The tab determines which subset of the loaded context you are looking at.

Typing in Raw JSON marks the pane unsynchronized. Choose Sync to Node View when the text is ready to be parsed and displayed as nodes. Tree changes use the application’s shared view-refresh mechanism.

Synchronization is different from saving

Pane synchronization indicator
Green means the app has marked that tab’s Node View synchronized with its text; red means synchronization is needed. This is not the live-file consistency indicator.
Current Task Info
Reports application task information. The startup message says dummy data is loaded and points you to File → Open.
Live-file consistency
A separate save-related concept. The full opening/saving chapter will document its exact source-dependent transitions; do not infer disk equality from a pane’s green synchronization light.

The old help’s background-thread-count LED explanation does not describe the current shared tab implementation.

Know what you are copying

  1. Main-window Import 'BaseContext' Json from Clipboard: an entire BaseContext-level import, not a single tab array.
  2. Tools → Export 'BaseContext' JSON to Clipboard: exports through the main-window view, not merely the active tab’s text.
  3. Raw JSON → Import from Clipboard / Export to Clipboard: replaces or copies the text shown for that tab.
  4. Node View → Copy This Node’s Text: copies only the selected node’s representation.

A clipboard export does not save live NMS files. Match pasted data to the exact destination instead of assuming every JSON-shaped document is interchangeable.

Text tools

Pretty Print first parses text into the model, then refreshes formatted text and nodes. Search Text is provided in each tab’s custom text menu and opens Search Backward, Search Forward, and Close controls.

Highlight In Text Box is read-only navigation from a selected node. It refuses when the displayed text and captured node structure cannot be safely matched; refusal does not synchronize or rewrite the data.

A reliable editing rhythm

  1. Confirm you loaded the intended source.
  2. Make one understandable change.
  3. If you edited text, synchronize deliberately before using tree-based data operations.
  4. Inspect the resulting records.
  5. Save only when you intend to write the selected live target.
