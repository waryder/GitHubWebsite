Menu Reference

Current top-level labels, with the effect of each action.

This is an initial top-level menu reference. Detailed slot-picker, backup, and restore walkthroughs remain on the writing checklist.

File

Open NMS Save File
Opens the existing slot-based NMS loading workflow. Its dialog includes Pick Folder..., Load Slot, and Close. Opening a picker and completing a load are different actions.
Save NMS Save File
For data loaded through the NMS workflow, uses the retained source and context to encode and write the selected data/metadata pair after confirmation. Review the actual warning and destination. This is a disk-writing operation, not a clipboard export.

The current File menu does not offer the old help’s Save As item.

Full Live Save Backup

Creates a full live-source-tree backup through its confirmation/controller workflow. Backups are stored under the application-root Full NMS Save Backups folder. This backs up disk data, not unsaved edits held only in the editor.

Do not confuse this with Backup a Base or Backup this Inventory; those are selected-record operations.

Full Live Save Restore

Shows manual restoration instructions. The application does not automatically delete or restore save files from this menu item. Its Copy Text button copies the instructions; Close dismisses them.

The manual commands described by the app can replace files when a person runs them. Review the app-generated paths, choose the intended backup, close the game, and protect anything you wish to keep before performing a manual restore.

Tools

Export 'BaseContext' JSON to Clipboard
Copies JSON through the main-window view to the clipboard using the existing export handler. It does not save it to an NMS data file.

Help

Open Help
The current app opens its bundled help/index.html in your default browser. This review site is separate and has not replaced that bundled help or changed the menu.

Right-click commands

These are conditional, rather than permanent top-level menu items:

  1. Common node actions: Toggle Expansion 2 Levels, Highlight In Text Box, Copy This Node’s Text.
  2. Base Processing: Restore a Base on the base-array root; Backup a Base on a base record; Delete Node. See the detailed guide.
  3. Starship Processing: Delete Node; its type-specific safeguards will be covered in the starship chapter.
  4. Inventory Processing: Backup this Inventory and Replace Items from Backup on eligible inventory nodes.
  5. Teleport Endpoints: Set Player Location to this Endpoint on eligible endpoint records.
  6. Right-button drag selection: Delete N Nodes.
  7. Raw JSON: Search Text alongside the text editor’s standard menu.

Availability depends on the tab and the particular node you click. This list identifies the commands; it is not a substitute for the still-unwritten safety and behavior details of each feature.
