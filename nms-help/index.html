First review edition. This is a separate draft of the new help facility. Base Processing is the first detailed feature guide; the remaining feature chapters are listed below for the next writing pass. These pages do not connect to the application or read your saves.

Start here

  1. Make an independent backup before editing, and close No Man’s Sky before writing live saves.
  2. The application starts with dummy data. Choose File → Open NMS Save File to load your data.
  3. Make a small change, inspect the result, and use File → Save NMS Save File only when you intend to write the selected live save.

Changing app data and saving it to disk are separate actions. A green pane-synchronization indicator is not a promise that your live save has been saved.

A good first review

Open the Base Processing guide. Can you find a task quickly, follow the steps, and tell whether an action changes app data, writes a backup file, or writes a live save? That distinction should remain obvious throughout the help.
