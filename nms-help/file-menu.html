Main Window → Menu Bar → File → Open NMS Save File

Open NMS Save File

Opens the slot picker. It does not change the loaded app data until a load is confirmed.

Open Open NMS Save File help →

Main Window → Menu Bar → File → Open NMS Save File → Storage:

Storage:

Displays Steam. This is a fixed label, not a selectable platform setting.

Main Window → Menu Bar → File → Open NMS Save File → Save Path:

Save Path:

The directory scanned for the slot list. The app prefers a usable remembered folder; otherwise it searches the NMS root for the first alphabetically sorted st_* account folder. This displayed path is not itself a promise that a save is loaded.

Main Window → Menu Bar → File → Open NMS Save File → Save Path: → Pick Folder...

Pick Folder...

Opens Pick NMS Save Folder. After choosing a folder, Confirm preference disk write asks whether to remember it. OK writes the preference and rescans; Cancel preserves the existing path and selection. This changes a preference, not game-save content.

Main Window → Menu Bar → File → Open NMS Save File → Game Slot:

Game Slot:

Choose a slot from Slot N - <save name>. Slots are ordered numerically. Names come from the newest readable metadata record; missing names and unreadable metadata have explicit fallback labels.

Main Window → Menu Bar → File → Open NMS Save File → Save File:

Save File:

Disabled display-only dropdown showing filename, Auto/Manual type and embedded timestamp. It is not an Auto/Manual chooser. Load Slot selects by validated metadata timestamps; the preview on a tie is not a guaranteed load target.

Main Window → Menu Bar → File → Open NMS Save File → Modified:

Modified:

Timestamp read from the displayed file’s mf_ metadata, formatted in local time as YYYY-MM-DD HH:MM:SS. It is not the filesystem modification time. Unknown or unreadable metadata is shown explicitly.

Main Window → Menu Bar → File → Open NMS Save File → Save Name:

Save Name:

Name from the displayed file’s metadata. No file selected or unreadable metadata produces the corresponding placeholder.

Main Window → Menu Bar → File → Open NMS Save File → Description:

Description:

Summary from the displayed file’s metadata; an unreadable record shows its read error.

Main Window → Menu Bar → File → Open NMS Save File → Load Slot

Load Slot

Warns before replacing all currently loaded app data, including unsaved edits. Requires the slot’s Auto/Manual data files and both mf_ companions with valid positive timestamps. Selects the newer embedded timestamp. Successful confirmations close the picker before decoding and refreshing all four tabs.

Main Window → Menu Bar → File → Open NMS Save File → Load Slot → Equal save timestamps

Equal save timestamps

When timestamps match, OK loads the Manual file and Cancel abandons loading. There is no silent Auto/Manual tie choice.

Main Window → Menu Bar → File → Open NMS Save File → Load Slot → Loaded Main / Expedition context

Loaded Main / Expedition context

There is no visible context selector. ActiveContext Main selects BaseContext; Season selects ExpeditionContext. A missing marker permits legacy Main-only loading only when no ExpeditionContext exists. Invalid or ambiguous data is rejected instead of silently choosing another branch.

Main Window → Menu Bar → File → Open NMS Save File → Load Slot → Loading data, please wait…

Loading data, please wait…

Non-cancellable progress while the selected data is decoded and the views are populated. The main window is temporarily disabled. A picker preview alone has not loaded data.

Main Window → Menu Bar → File → Save NMS Save File

Save NMS Save File

For a loaded NMS source, writes the retained data file and its metadata companion, using the context selected at load. Browsing another folder afterward does not retarget this save. The inactive context and unrelated root data are preserved.

Main Window → Menu Bar → File → Save NMS Save File → Unsynchronized text check

Unsynchronized text check

Unsynchronized Raw JSON in any tab blocks saving. Synchronize your intended edits before trying again.

↑ This page’s hierarchy

Main Window → Menu Bar → File → Save NMS Save File → Confirm Live Save Write

Confirm Live Save Write

Names the retained slot and Main/Expedition context, warns to close No Man’s Sky, and defaults to Cancel. Confirm only when that is the data and destination you intend to write.

↑ This page’s hierarchy

Main Window → Menu Bar → File → Save NMS Save File → Saving and verifying…

Saving and verifying…

Writes the selected data/metadata pair and reads back both files before reporting saved. This is not a durable backup, and the two files are not replaced as one atomic pair. The app does not continuously monitor external game-file changes.

Main Window → Menu Bar → File → Full Live Save Backup

Full Live Save Backup

Creates a standard full live-save-folder backup after explicit confirmation. This is separate from exporting one base or inventory.

Main Window → Menu Bar → File → Full Live Save Backup → Source and destination proposal

Source and destination proposal

Shows the resolved full live NMS source tree, proposed timestamped backup destination and planning information before output creation. The source follows the remembered/default folder policy, not merely the currently displayed slot.

↑ This page’s hierarchy

Main Window → Menu Bar → File → Full Live Save Backup → Save

Save

Authorizes copying the proposed live disk tree into Full NMS Save Backups under the application root. A progress notice covers copy and verification; completion reports the resulting directory. Unsaved editor data is not first written to disk and is not included as if it were saved.

↑ This page’s hierarchy

Main Window → Menu Bar → File → Full Live Save Backup → Cancel

Cancel

Abandons the proposed backup without creating its output directory.

Main Window → Menu Bar → File → Full Live Save Restore

Full Live Save Restore

Opens Full Live Save Restore — Manual Instructions. It is instructions-only, not an automated restore feature.

Main Window → Menu Bar → File → Full Live Save Restore → Manual instructions

Manual instructions

Read-only selectable text identifies the runtime backup root and live NMS directory, warns that the example deletes all live NMS directory contents, and describes copying a selected backup back into that directory. The app does not execute these commands. Do not run restoration commands with the game open.

↑ This page’s hierarchy

Main Window → Menu Bar → File → Full Live Save Restore → Copy Text

Copy Text

Copies the displayed instructions to the clipboard. It does not execute them or restore a file.

↑ This page’s hierarchy

Main Window → Menu Bar → File → Full Live Save Restore → Close

Close

Closes the instructions without changing save files. Enter also closes the dialog.
