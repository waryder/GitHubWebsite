Examples → Sort my bases

Sort my bases

Follow Base Processing → Node View → Sort By Gal, Sys, Name. Set Move Freighter to Top on Sort as desired, synchronize any Raw JSON edits, sort and review. File → Save NMS Save File is separate.

Examples → Find the JSON for a node

Find the JSON for a node

Follow the tab → Node View → Right-click menu → Highlight In Text Box. Select the node and use the command. It navigates without applying edits; if correspondence is stale, it refuses rather than choosing a source.

Examples → Gather resources into one container

Gather resources into one container

Follow Inventory Processing → Node View → Inventory Organizer. Choose sources, select a destination for Resources, review overflow and expansion settings, click Review Moves, inspect the proposal and choose Apply to app data. Save the live file separately when intended.
