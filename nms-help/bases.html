Base Processing → Node View

Node View

Shows the loaded context’s PlayerStateData.PersistentPlayerBases array.

Base Processing → Node View → Sort By Gal, Sys, Name

Sort By Gal, Sys, Name

Reorders complete base records by galaxy, then system, then Name. The result is reflected in app data and views; it does not itself write an NMS save.

Base Processing → Node View → Move Freighter to Top on Sort

Move Freighter to Top on Sort

Checked by default. After the ordinary sort, moves the first base whose Name is empty to index 0. The current implementation uses an empty name as its freighter-identification rule.

Base Processing → Node View → Base tree

Base tree

Expand or collapse the base-array and individual records.

Base Processing → Node View → Base tree → Base record label

Base record label

Shows a zero-based index, dictionary size, galaxy name, system, Parts count and base name. Parts is the number of entries in the base’s Objects array. Empty names display as Unnamed Freighter Base.

↑ This page’s hierarchy

Base Processing → Node View → Base tree → Left-button drag and drop

Left-button drag and drop

Move complete base records to reorder them. For siblings, an upward drag places the record before the target and a downward drag places it after. Cross-parent drops are placed after the target. The generic guard requires compatible array/dictionary parents and refuses moving a parent’s last child; it does not validate arbitrary game-data restructuring.

↑ This page’s hierarchy

Base Processing → Node View → Base tree → Right-button drag selection → Delete N Nodes

Right-button drag selection → Delete N Nodes

Hold the right mouse button and drag across visible nodes. Releasing opens Delete N Nodes for that selection; confirmation gates removal. Check that the selection contains complete intended records, not unwanted child fields.

↑ This page’s hierarchy

Base Processing → Node View → Base tree → Right-click menu

Right-click menu

Availability depends on whether you click the base-array root, a base record or another node.

Base Processing → Node View → Base tree → Right-click menu → Restore a Base

Restore a Base

Appears when you right-click the top-level base-array node. Opens Restore A Base To First Position In Tree, reads a selected *.nms_base.json file, and adds that base record at index 0. It does not search for or replace a same-name base; duplicates are possible. The change is in app memory until you save.

↑ This page’s hierarchy

Base Processing → Node View → Base tree → Right-click menu → Backup a Base

Backup a Base

Appears on a complete base record. Writes that base’s Node View data to a selected JSON file, using the *.nms_base.json file filter. The suggested name comes from the base name, or default for an empty name. This is one base record, not a full-save backup.

↑ This page’s hierarchy

Base Processing → Node View → Base tree → Right-click menu → Toggle Expansion 2 Levels

Toggle Expansion 2 Levels

Collapses an expanded node or expands a collapsed node through the configured two-level helper. This changes only what is visible.

↑ This page’s hierarchy

Base Processing → Node View → Base tree → Right-click menu → Highlight In Text Box

Highlight In Text Box

Selects the corresponding line in Raw JSON without changing data. It refuses if the captured node structure and current text cannot be matched reliably; it does not silently synchronize them.

↑ This page’s hierarchy

Base Processing → Node View → Base tree → Right-click menu → Copy This Node's Text

Copy This Node's Text

Copies the selected node’s displayed label to the clipboard. It does not serialize that node’s full JSON or export the complete record.

↑ This page’s hierarchy

Base Processing → Node View → Base tree → Right-click menu → Delete Node

Delete Node

After confirmation, removes the selected node from the in-app structure. Selecting a child field removes that field, not the whole base. Review the target before confirming; saving to live files is separate.

Base Processing → Raw JSON

Raw JSON

Contains the base array, not the full save and not the complete BaseContext.

Base Processing → Raw JSON → Synched to Node View — status indicator

Synched to Node View — status indicator

Shows whether the app has marked this tab’s Raw JSON and Node View synchronized. Green means synchronized; red means synchronization is needed. This does not mean the live save has been written.

↑ This page’s hierarchy

Base Processing → Raw JSON → Sync to Node View

Sync to Node View

Parses this tab’s current Raw JSON, updates the app’s model, and rebuilds the Node View. Use after direct text edits; invalid JSON must be corrected before it can be used as structured data.

↑ This page’s hierarchy

Base Processing → Raw JSON → Pretty Print

Pretty Print

Parses the current text into the model, reloads indented JSON, and rebuilds the Node View. It therefore applies parseable text edits as well as formatting them.

↑ This page’s hierarchy

Base Processing → Raw JSON → JSON text editor

JSON text editor

Displays the loaded context’s base-array data. You can edit the JSON directly. Line numbers identify text lines; the current line is highlighted. Text is not line-wrapped, so long lines scroll horizontally.

↑ This page’s hierarchy

Base Processing → Raw JSON → Right-click menu

Right-click menu

The editor supplies its standard editing commands plus Search Text.

Base Processing → Raw JSON → Right-click menu → Standard editing commands

Standard editing commands

Undo, Redo, Cut, Copy, Paste, Delete and Select All operate on the text editor, subject to its current selection and available edit history. These are text operations, not a general undo facility for tree operations.

Base Processing → Raw JSON → Right-click menu → Standard editing commands → Undo

Undo

Reverses the most recent text-editor edit when an undo step is available. It is not an application-wide undo for sorting, upgrades, node deletion or inventory organization.

↑ This page’s hierarchy

Base Processing → Raw JSON → Right-click menu → Standard editing commands → Redo

Redo

Reapplies a text-editor change that was undone, when redo history is available.

Search Text

Enter search term

Base Processing → Raw JSON → Right-click menu → Search Text → Search Backward

Search Backward

Finds the preceding occurrence from the current cursor. No more occurrences produces End of Search; the implementation does not wrap to the opposite end.

↑ This page’s hierarchy
