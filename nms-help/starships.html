Node View

Starship Processing → Node View → Upgrade Starships

Upgrade Starships

Opens Which Starships Would You Like To Upgrade? after checking that all tabs are synchronized. Applies selected upgrades to app memory; saving game files remains separate.

Open Upgrade Starships help →

Starship Processing → Node View → Upgrade Starships → Upgrade behavior notice

Upgrade behavior notice

Selected ships receive reference statistics and S-class settings. Non-Corvette technology items are replaced entirely with reference equipment; existing extras, trails, figurines and module seeds can be lost. Corvettes preserve equipment/build parts and add missing technology. Capacity targets 60 technology slots; equipment/capacity failure can skip that portion while statistics/class still apply. Unsupported models or invalid statistics/class references are rejected.

Starship checkboxes

Check the ships to process. Selection uses each ownership slot’s index, so duplicate names remain distinct. Nothing is selected by default. Empty selection and Cancel make no changes.

Starship tree

Unoccupied slots

Empty ownership slots are shown as Slot X - (unoccupied). They are not ordinary unnamed ships to upgrade.

↑ This page’s hierarchy

Starship Processing → Node View → Starship tree → Left-button drag and drop

Left-button drag and drop

The shared tree supports structural drag and drop with parent-type and last-child guards. These generic checks are not proof that an arbitrary ship move preserves every game-side association. Use a backup and inspect results; the broader ship move/swap/sort design is separate from the deletion safeguards.

Starship Processing → Node View → Starship tree → Right-button drag selection → Delete N Nodes

Right-button drag selection → Delete N Nodes

Collects a visible-node range and routes deletion through the ship-specific controller. Only valid complete ownership records may be deleted; arbitrary nested-field deletion is refused.

Highlight In Text Box

Selects the corresponding line in Raw JSON without changing data. It refuses if the captured node structure and current text cannot be matched reliably; it does not silently synchronize them.

Copy This Node's Text

Copies the selected node’s displayed label to the clipboard. It does not serialize that node’s full JSON or export the complete record.

Starship Processing → Node View → Starship tree → Right-click menu → Delete Node

Delete Node

Routes through type-aware ship deletion. It preserves the fixed ownership-slot structure using an appropriate empty template, handles associated appearance/build cleanup, and refuses deletion of the last occupied ship. The linked Corvette editor index follows the approved deletion rules. Review the confirmation; this edits app memory, not the disk by itself.

Starship Processing → Raw JSON

Raw JSON

Contains the ship-ownership array for the loaded context.

Starship Processing → Raw JSON → Synched to Node View — status indicator

Synched to Node View — status indicator

Shows whether the app has marked this tab’s Raw JSON and Node View synchronized. Green means synchronized; red means synchronization is needed. This does not mean the live save has been written.

↑ This page’s hierarchy

Starship Processing → Raw JSON → Sync to Node View

Sync to Node View

Parses this tab’s current Raw JSON, updates the app’s model, and rebuilds the Node View. Use after direct text edits; invalid JSON must be corrected before it can be used as structured data.

↑ This page’s hierarchy

Starship Processing → Raw JSON → Pretty Print

Pretty Print

Parses the current text into the model, reloads indented JSON, and rebuilds the Node View. It therefore applies parseable text edits as well as formatting them.

↑ This page’s hierarchy

Starship Processing → Raw JSON → JSON text editor

JSON text editor

Displays the loaded context’s ShipOwnership array. You can edit the JSON directly. Line numbers identify text lines; the current line is highlighted. Text is not line-wrapped, so long lines scroll horizontally.

↑ This page’s hierarchy

Starship Processing → Raw JSON → Right-click menu

Right-click menu

The editor supplies its standard editing commands plus Search Text.

Starship Processing → Raw JSON → Right-click menu → Standard editing commands

Standard editing commands

Undo, Redo, Cut, Copy, Paste, Delete and Select All operate on the text editor, subject to its current selection and available edit history. These are text operations, not a general undo facility for tree operations.

Starship Processing → Raw JSON → Right-click menu → Standard editing commands → Undo

Undo

Reverses the most recent text-editor edit when an undo step is available. It is not an application-wide undo for sorting, upgrades, node deletion or inventory organization.

↑ This page’s hierarchy

Starship Processing → Raw JSON → Right-click menu → Standard editing commands → Redo

Redo
