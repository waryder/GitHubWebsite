Main Window → Menu Bar → File → Open NMS Save File → Storage:

Storage:

Displays Steam. This is a fixed label, not a selectable platform setting.

Main Window → Menu Bar → File → Open NMS Save File → Save Path:

Save Path:

The directory scanned for the slot list. The app prefers a usable remembered folder; otherwise it searches the NMS root for the first alphabetically sorted st_* account folder. This displayed path is not itself a promise that a save is loaded.

Main Window → Menu Bar → File → Open NMS Save File → Save Path: → Pick Folder...

Pick Folder...

Opens Pick NMS Save Folder. After choosing a folder, Confirm preference disk write asks whether to remember it. OK writes the preference and rescans; Cancel preserves the existing path and selection. This changes a preference, not game-save content.

Main Window → Menu Bar → File → Open NMS Save File → Game Slot:

Game Slot:

Choose a slot from Slot N - <save name>. Slots are ordered numerically. Names come from the newest readable metadata record; missing names and unreadable metadata have explicit fallback labels.

Main Window → Menu Bar → File → Open NMS Save File → Save File:

Save File:

Disabled display-only dropdown showing filename, Auto/Manual type and embedded timestamp. It is not an Auto/Manual chooser. Load Slot selects by validated metadata timestamps; the preview on a tie is not a guaranteed load target.

Main Window → Menu Bar → File → Open NMS Save File → Modified:

Modified:

Timestamp read from the displayed file’s mf_ metadata, formatted in local time as YYYY-MM-DD HH:MM:SS. It is not the filesystem modification time. Unknown or unreadable metadata is shown explicitly.

Main Window → Menu Bar → File → Open NMS Save File → Save Name:

Save Name:

Name from the displayed file’s metadata. No file selected or unreadable metadata produces the corresponding placeholder.

Main Window → Menu Bar → File → Open NMS Save File → Description:

Description:

Summary from the displayed file’s metadata; an unreadable record shows its read error.

Main Window → Menu Bar → File → Open NMS Save File → Load Slot

Load Slot

Warns before replacing all currently loaded app data, including unsaved edits. Requires the slot’s Auto/Manual data files and both mf_ companions with valid positive timestamps. Selects the newer embedded timestamp. Successful confirmations close the picker before decoding and refreshing all four tabs.

Main Window → Menu Bar → File → Open NMS Save File → Load Slot → Equal save timestamps

Equal save timestamps

When timestamps match, OK loads the Manual file and Cancel abandons loading. There is no silent Auto/Manual tie choice.

Main Window → Menu Bar → File → Open NMS Save File → Load Slot → Loaded Main / Expedition context

Loaded Main / Expedition context

There is no visible context selector. ActiveContext Main selects BaseContext; Season selects ExpeditionContext. A missing marker permits legacy Main-only loading only when no ExpeditionContext exists. Invalid or ambiguous data is rejected instead of silently choosing another branch.

Main Window → Menu Bar → File → Open NMS Save File → Load Slot → Loading data, please wait…

Loading data, please wait…

Non-cancellable progress while the selected data is decoded and the views are populated. The main window is temporarily disabled. A picker preview alone has not loaded data.

Main Window → Menu Bar → File → Open NMS Save File → Close

Close

Dismisses the picker without loading a slot. Closing does not discard the current app data.
